# Personal Portfolio

Modern personal portfolio built with Next.js, React, Tailwind CSS, and shadcn-style components.

## Sections

- Home
- About Me
- Skills
- Projects
- Education
- Achievements / Certifications
- Resume
- Contact Me

## Run

```bash
npm install
npm run dev
```

## Edit content

Update the centralized data in `src/data/portfolio.ts` to replace the placeholder name, summary, projects, education, and contact details with your real resume information.
